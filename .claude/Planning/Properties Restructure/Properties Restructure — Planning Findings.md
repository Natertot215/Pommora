#### Edge Rules

Rules earlier agents chose that work as designed and stay as they are under Decisions P-3; *Morning Report › §What Stays the Same* states them in plain English.

- **Folded Names:** two definitions, or two options, whose names fold equal under case and accents read as the first; the registry read admits the first definition per folded name and the first option, and an option duplicate leaves the file on the next option write (`9c2850b3b`; `Core/Properties/propertiesRegistry.ts`).
- **Refill:** option words decode exactly, so a stashed word whose option was renamed or deleted while the property was removed refills nothing (`9aeb29271`).
- **One-Item Lists:** `encodeValue` writes a Select or Status pick as a one-item list (`Core/Properties/propertyValue.ts`), so Obsidian reads the key as a list.
- **Grouping and Sorting:** the type record decides what groups and sorts, so Checkbox can't group and Context can't sort (`ee86c919b`).
- **Mass Pick:** a pick across several selected rows clears the option when every row already holds it and sets it otherwise (`Core/Properties/Pickers/massAssign.ts`).
- **First Line:** the one-line text field edits a value's first line and carries later lines through untouched (`b80a7b12a`).
- **Custom Sort:** a Custom option sort always reads ascending, ignoring Default and Reversed (`Core/Views/Pipeline/sort.ts`).
- **Restored Space Options:** a restored Space loses an option deleted while it sat in the Trash.
