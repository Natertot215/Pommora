#### Guiding Principles

- **The file is the fact.** Last Modified is the file's modification time and Creation Time is the instant in the page's `PageID` ULID. Any second source of either — a key, a cache read as truth, a stamp written anywhere — is a defect, whoever wrote it.
- **A rewrite the user did not make keeps the file's time.** Sweeps, migrations, adoption, and journaled cascades go through `rewritePreservingTimes`; a user's own write — a value edit, a body save, a governed-root write — takes now. Every writer sits on one side of that line, and a writer on the wrong side is a finding.
- **One writer per fact, one reader per shape.** `loadValues` is the one batch; `PageValues` the one carrier; `STAMP_TYPE` the one id-to-type map; `RESERVED_LABEL` the one label source. A parallel path, however small, is reported.
- **Nothing expensive on a high-frequency trigger.** A push refreshes only the pages it names. A body save must not cost the container; a rename must not cost the nexus.
- **Main owns the filesystem, the envelope never throws, and the shared contract imports no fs.** A raw channel, a `.then` with no failure branch, or a Node import under `src/shared` is a finding.
- **The vault is the user's.** The migration ran once, with a backup at `~/NexusOS-stamp-backup-09-01-2026/`; report anything the migration could have left inconsistent, but never touch `~/NexusOS`.
- **Simplicity before severity.** Prefer the finding that removes code to the one that adds a guard; name who produces a state before defending against it.
