### Before React — The SwiftUI Build

Pommora ran as a native SwiftUI app from 05-13-2026, after three days of specification in which React and Electron were the stated direction. That build defined the initial paradigm over roughly a month and was archived on 07-05 at `// The Studio // Archive // Pommora`; its commits remain in this repository's own ancestry.

- **Specification and the stack pivot** (05-10 → 05-15) — the repository opened on documents alone, inverted to SwiftUI on 05-13, and built the Nexus foundation: a value type with an inline ULID generator, security-scoped bookmarks, and a persisted identity.
- **The paradigm scaffolding** (05-16 → 05-18) — every entity in the locked paradigm received a Codable type, a validator, and an observable manager, with atomic I/O primitives and CRUD end to end.
- **The editor** (05-18 → 05-22) — a WKWebView CodeMirror fork and Milkdown were each wired and abandoned before native TextKit 2 shipped, carrying horizontal rules, styler-driven lists, folder adoption, and a renderer-drawn blockquote.
- **The layout refactor and its undo** (05-22 → 05-23) — ParadigmV2 wrapped entity folders under `Pages/`, `Items/`, and `Agenda/`; Flat-Layout dropped those wrappers one day later, classifying by sidecar filename instead of position.
- **Properties and the SQLite index** (05-23 → 05-27) — eleven lettered phases delivered the property system, a per-nexus GRDB index, and a working schema editor. A third Pages-side tier was built and reverted inside the same cycle.
- **Relations unified** (05-28 → 05-31) — tier tagging and relation properties collapsed onto one pipeline, a native icon picker replaced its third-party dependency, and a manager de-duplication removed roughly 590 lines with no behavior change.
- **Items built, then deleted** (06-01 → 06-10) — Items converted to Markdown, gained a template engine and a floating window across two rounds, and were removed outright nine days later. Item-named Swift files went from 75 to one in a single evening.
- **Late Swift** (06-10 → 06-19) — the three context tiers decoupled, Sets joined as a third operational tier, and a 19-task Views cluster shipped after its hand-built table was abandoned and salvaged onto `NSOutlineView`. An FSEvents watcher and a Nexus header closed it.
